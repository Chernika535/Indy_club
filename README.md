# Инди Клуб

Атлас независимой культуры. В галерее миров можно найти игру, зин или автора, перейти из работы в профиль и дальше в соседний мир. Шесть миров отличаются собственными сценами и устройством выставок.

## Открыть сайт через GitHub Pages

Сайт опубликован по адресу https://chernika535.github.io/Indy_club/. GitHub Pages берёт файлы из папки `/docs` в ветке `main` и обновляет сайт после коммитов в эту ветку. Настройки источника доступны в разделе **Settings → Pages**.

Сайт состоит из HTML, CSS и JavaScript. Сборка, ключи API и платные сервисы для этого выпуска не нужны. На Windows можно проверить изменения локально. В PowerShell из папки репозитория выполните `py -m http.server 8000 --directory docs` и откройте http://localhost:8000/. Команда использует Python 3.

## Обновить каталог

В [docs/catalog.mjs](docs/catalog.mjs) находятся миры, авторы, работы, знакомые произведения и подборки. При добавлении работы укажите уникальный `id`, автора из `people`, формат из `types`, один или несколько миров, темы, язык, проверенную внешнюю ссылку и известные предупреждения. Названия тем используются поиском и рекомендациями. В [docs/discovery.mjs](docs/discovery.mjs) можно расширить словарь поиска.

Исходные страницы авторов и работ доступны по ссылкам из каталога. Оформление порталов и карточек сделано для клуба. Темы, предупреждения и связи со знакомыми произведениями отражают редакционную разметку пробного каталога.

## Что проверить перед расширением

Откройте «Мой вкус», выберите «Ведьмак» и аспект «фольклор». Из рекомендаций перейдите в работу, затем в профиль автора и мир Slavic. В поиске введите «игра про фольклор без демонов» и проверьте, что Black Book: Prologue скрыта. Сохраните работу или автора, перезагрузите страницу и откройте «Моё».

Сохранения и исключения живут в браузере. Поиск обрабатывает известные темы, имена и названия. Каталог редактируется через коммиты в GitHub. Общие аккаунты, публикации, мастерская и синхронизация сохранений включаются после подключения Supabase.

## Подключить регистрацию и мастерскую

Публичная галерея продолжает работать на GitHub Pages. Регистрация и общие данные требуют проекта Supabase, которым владеет администратор клуба.

В проекте Supabase запустите [миграцию](supabase/migrations/001_portal.sql) через SQL Editor. В Authentication → URL Configuration задайте Site URL и разрешённый Redirect URL `https://chernika535.github.io/Indy_club/`. Включите вход по почте, подтверждение адресов и настройте собственный SMTP для писем посетителям. Письмо подтверждения или восстановления нужно открыть в браузере, где запрашивали ссылку.

Добавьте URL проекта и ключ `sb_publishable_…` в [docs/backend-config.mjs](docs/backend-config.mjs). Только ключ для браузера можно хранить в публичном репозитории. Ключи `sb_secret_…`, `service_role` и данные SMTP хранятся в настройках Supabase.

После развёртывания проверьте двумя отдельными аккаунтами. Первый создаёт профиль и черновик, второй и гость его не видят. После открытия профиля и публикации материал должен появиться в каталоге и выбранном мире. Закрытие профиля убирает материал из публичной выдачи. Сохранения вошедших пользователей разделены по аккаунтам. Сохранения гостя остаются в его браузере.

Работы открываются по ссылкам авторов. Публикации отображаются в клубе обычным текстом. Для открытого набора авторов потребуется отдельный этап модерации и обработки жалоб.
