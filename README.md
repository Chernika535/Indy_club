# Инди Клуб

Атлас независимой культуры. В пробном выпуске можно найти игру, зин или автора, перейти из работы в профиль и дальше в соседний мир. Это этап проверки идеи из продуктового документа.

## Открыть сайт через GitHub Pages

В репозитории откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/docs** и нажмите **Save**. После первого развёртывания GitHub покажет ссылку на сайт. Для этого репозитория ожидаемый адрес — https://chernika535.github.io/Indy_club/.

Сайт состоит из HTML, CSS и JavaScript. Сборка, ключи API и платные сервисы для этого выпуска не нужны. На Windows можно проверить изменения локально. В PowerShell из папки репозитория выполните `py -m http.server 8000 --directory docs` и откройте http://localhost:8000/. Команда использует Python 3.

## Обновить каталог

В [docs/catalog.mjs](docs/catalog.mjs) находятся миры, авторы, работы, знакомые произведения и подборки. При добавлении работы укажите уникальный `id`, автора из `people`, формат из `types`, один или несколько миров, темы, язык, проверенную внешнюю ссылку и известные предупреждения. Названия тем используются поиском и рекомендациями. В [docs/discovery.mjs](docs/discovery.mjs) можно расширить словарь поиска.

Исходные страницы авторов и работ доступны по ссылкам из каталога. Оформление порталов и карточек сделано для клуба. Темы, предупреждения и связи со знакомыми произведениями отражают редакционную разметку пробного каталога.

## Что проверить перед расширением

Откройте «Мой вкус», выберите «Ведьмак» и аспект «фольклор». Из рекомендаций перейдите в работу, затем в профиль автора и мир Slavic. В поиске введите «игра про фольклор без демонов» и проверьте, что Black Book: Prologue скрыта. Сохраните работу или автора, перезагрузите страницу и откройте «Моё».

Сохранения и исключения живут в браузере. Поиск обрабатывает известные темы, имена и названия. Каталог редактируется через коммиты в GitHub. Общие аккаунты, публикации, мастерская и синхронизация входят в следующий этап и требуют серверной части и общей базы данных.
